## 6.1. Установка сертификатов

Корневой сертификат **«Russian Trusted Root CA»** нужен, чтобы операционная система
доверяла внутренним ресурсам Альфа-Банка.

### macOS

1. Скачайте архив: `https://disk.yandex.ru/d/gSNOn8RFcEQkqg` и разархивируйте.
2. Откройте файл сертификата двойным кликом — приложение «Связка ключей» откроется
   автоматически и добавит сертификат.
3. Найдите добавленный сертификат в «Связке ключей», дважды кликните по нему и
   раскройте раздел **Доверие**.
4. В поле «При использовании этого сертификата» выберите **Всегда доверять**.
5. Закройте окно и введите пароль администратора, если macOS его запросит.

### Windows

1. Скачайте архив с сертификатами и установщиком:
   `https://disk.yandex.ru/d/wvBzlwHrK15Sjw` и распакуйте.
2. Запустите скрипт `apply_cert.bat` из распакованной папки — сертификаты установятся
   автоматически.

**Если не удалось — установите вручную:**

1. Скачайте файл сертификата: `https://disk.yandex.ru/d/jRkEcjgT4njcPQ` и разархивируйте.
   Внутри два файла: `russian_trusted_root_ca.cer` и `russian_trusted_root_ca_gost_2025.cer`.
   Оба нужно установить как доверенные.
2. Двойной клик по первому файлу `.cer` → Открыть → Установить сертификат.
3. Выберите «Текущий пользователь» в окне «Мастер импорта сертификатов» и нажмите «Далее».
4. Выберите «Поместить все сертификаты в следующее хранилище» и нажмите «Обзор».
5. Выберите «Доверенные корневые центры сертификации» и нажмите «Далее» — для установки
   корневых сертификатов.
6. Выберите «Автоматически выбрать хранилище на основе типа сертификата» и нажмите
   «Далее» — при установке выпускающих сертификатов.
7. Повторите шаги 2–6 для второго файла `.cer` из архива.

## 6.2. KiloCode VSCode (рекомендуется)

### Установка IDE

Visual Studio Code: `https://code.visualstudio.com/`

### Установка Kilo Code

1. Запустите VS Code.
2. Перейдите на вкладку «Расширения» (Extensions) — иконка с квадратиками на левой
   панели или `Ctrl+Shift+X`.
3. В строке поиска введите **Kilo Code**.
4. Найдите расширение в списке, нажмите «Установить» (Install).
5. После установки появится иконка Kilo Code на левой панели.

### Настройка плагина

Откройте интерфейс Kilo Code и найдите меню настроек (иконка «шестерёнки» в правом
верхнем углу чата). Если кнопка настроек не реагирует — сначала один раз нажмите
«Bring my own key» в стартовом экране Kilo.

**Выбор языка:** вкладка Language → Русский (рекомендуется; влияет на язык общения ИИ).

**Подключение к корпоративной модели AlfaGen:**

1. В меню настроек перейдите во вкладку «Провайдеры» и нажмите «Подключить» напротив
   «Пользовательский провайдер».
2. Заполните поля формы:

| Поле | Значение |
|------|----------|
| ID провайдера | `alfagen` |
| Отображаемое имя | `alfagen` |
| Базовый URL | `https://alfagen.alfabank.ru/continue-dev/` |
| Альтернативный URL | `https://alfagen.alfabank.ru/continue-dev/v1` |
| API-ключ | Авторизоваться на `https://alfagen.alfabank.ru/`, раздел Enterprise Vibe Coding, скопировать ключ доступа |

3. Укажите имя и ID модели: `deepseek-ai/DeepSeek-V4-Flash-0731`.

## 6.3. OpenCode (альтернатива)

### Установка

```bash
# через npm (mac/linux/win)
npm i -g opencode-ai
# вызов: npx opencode-ai

# через curl (mac/linux)
curl -fsSL https://opencode.ai/install | bash

# через brew (mac)
brew install anomalyco/tap/opencode
```

Для OpenCode Desktop: `https://opencode.ai/download`

### Настройка

Отредактируйте (создайте при необходимости) файл:

- mac/linux: `~/.config/opencode/opencode.jsonc`
- windows: `%USERPROFILE%\.config\opencode\opencode.jsonc`

```jsonc
{
  "$schema": "https://opencode.ai/config.json",
  "provider": {
    "alfagen": {
      "name": "AlfaGen",
      "options": {
        "baseURL": "https://alfagen.alfabank.ru/continue-dev/",
        "apiKey": "вводим ключ из шага Добавление ключа"
      },
      "models": {
        "deepseek-ai/DeepSeek-V4-Flash-0731": {
          "name": "DeepSeek-V4-Flash",
          "limit": {
            "context": 1000000,
            "output": 30000
          }
        }
      }
    }
  }
}
```

> **Важно!** Не добавляйте префикс `Bearer` в поле `apiKey` — только сам ключ.

### Добавление ключа

1. Заходим на портал AlfaGen и выбираем плашку «Enterprise Vibe Coding» (или
   `https://alfagen.alfabank.ru/plugins`).
2. Откроется страница с ключом доступа.
3. Заходим в opencode в терминале (`opencode` или `npx opencode-ai`) и вводим `/connect`.
4. Выбираем AlfaGen, вставляем ключ со страницы «Enterprise Vibe Coding».
5. Выбираем нужную модель.

## 6.5. Безопасность локального окружения

- Не добавляйте API-ключи, сертификаты и локальные конфигурации в Git.
- Значение `apiKey` в примерах — заполнитель; используйте персональный ключ из
  портала AlfaGen и храните его в менеджере секретов или локальной конфигурации.
- Ссылки на внешние инструкции и поддержку могут измениться; при расхождении
  сверяйтесь с актуальным порталом AlfaGen.
