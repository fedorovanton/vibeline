## Краткая сводка

**Задача:** разработать сервис-прокси для цепочки «система-потребитель → LLM», который
выполняет **идентификацию**, **маскирование** и **демаскирование** персональных данных.

**Ключевые цифры:**

- Качество обработки — **≥ 95%**.
- Обработка текста — **до 100 000 токенов**.
- Latency — **≤ 1 секунды**, измеряется только время ответа нашего сервиса.
- RPS — **1000** (целевой), **2000** (бонус). Фактический прогон: разгон, средний
  ~330 RPS с пиками до 1000, до 200 одновременных коннектов в закрытом контуре.
- Призовой фонд — **2 300 000 ₽**.

Формат маскирования свободный: эталонной маски не существует, оценивается качество
сокрытия относительно оригинала. Детали — [07-clarifications.md](07-clarifications.md).

**Контракт:** один эндпоинт `POST /process` (`{payload, payload_id}` → `{result}`),
корреляция маскирование→демаскирование по `payload_id`.

**Дедлайн загрузки решения (zip):** 23 сентября 2026, 23:59 МСК.
