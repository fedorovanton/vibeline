# specs/api-alfagen/ — Контракт API AlfaGen

Каталог содержит документацию контрактов внешних сервисов, которые использует
решение для хакатона AlfaGen (Альфа-Банк).

## Содержимое

| Файл | Назначение |
|------|------------|
| [`alfagen-api-contract.md`](./alfagen-api-contract.md) | Полный контракт вызова корпоративной ИИ-модели AlfaGen (Enterprise Vibe Coding): эндпоинты, авторизация, схема запроса/ответа, примеры (в т.ч. на Go), обработка ошибок, лимиты. |
| [`check.sh`](./check.sh) | Bash-скрипт проверки работоспособности API AlfaGen. |
| [`.env.example`](./.env.example) | Пример файла окружения с переменной `ALFAGEN_API_KEY`. |

## Как пользоваться

### 1. Настроить ключ

Скопируйте пример окружения в корень репозитория и вставьте реальный ключ:

```bash
cp specs/api-alfagen/.env.example .env
# отредактируйте .env и вставьте ключ из раздела «Enterprise Vibe Coding»
# на портале https://alfagen.alfabank.ru/
```

> ⚠️ Файл `.env` игнорируется git (см. `.gitignore`). Никогда не коммитьте реальный ключ.
> Такой подход позволяет решению работать на любом ПК: пользователю достаточно
> положить ключ в `.env` — без правки кода и глобальных переменных окружения.

### 2. Проверить работоспособность API

```bash
# ключ автоматически подхватится из .env (если файл существует)
bash specs/api-alfagen/check.sh

# или ключ из переменной окружения (приоритетнее .env)
export ALFAGEN_API_KEY="ваш_ключ"
bash specs/api-alfagen/check.sh
```

Приоритет: переменная окружения `ALFAGEN_API_KEY` > файл `.env` в корне репозитория.

Подробнее о флагах и переменных — в [`check.sh`](./check.sh) и
[`alfagen-api-contract.md`](./alfagen-api-contract.md).

### 3. Использовать контракт в коде

Схема запроса/ответа и примеры (включая Go) — в
[`alfagen-api-contract.md`](./alfagen-api-contract.md).
