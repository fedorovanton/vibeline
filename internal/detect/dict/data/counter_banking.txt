# Банковские слова: признак того, что предложение — обращение клиента, а не
# рассказ о знаменитости. Читает только правило 4 контр-правил (T-51).
#
# Правило 4 снимает ФИО, если фамилия есть в counter_public и в предложении
# нет признака конкретного человека. «Юрий Гагарин хочет открыть вклад на год»
# — это клиент-однофамилец: в банковском тексте «вклад», «кредит», «перевод»
# указывают на клиента не хуже слова «клиент». Любое слово отсюда в том же
# предложении отменяет вето правила 4. Правило 1 (ролевое слово: «поэт
# Пушкин открыл вклад») справочник не трогает — ролевое слово сильнее.
#
# Запись — основа слова. Слово из текста сравнивается с САМОЙ ДЛИННОЙ
# записью, которой оно начинается: «кредит» покрывает «кредита»,
# «кредитный», «кредитку». Метка во втором столбце через табуляцию:
#
#   (пусто) — основа: совпадает любое слово, которое с неё начинается;
#   exact   — только слово целиком: «долг» не должен ловить «долго»,
#             «займ» — «займусь», «евро» — «Европу»;
#   except  — исключение: слово с этой основой банковским не считается,
#             даже если начинается с более короткой банковской основы:
#             «переводчик» — не «перевод», «договорились» — не «договор»;
#   venue   — учреждение, а не операция: «банк», «банка», «банкир». Слово
#             банковским не засчитывается и вето не отменяет: в новости
#             «Олег Тиньков продал долю в банке», в посте «к дню рождения
#             Фёдора Достоевского для соцсетей банка» и в объявлении «Банк
#             спонсирует выставку …» банк — автор или тема текста, а не
#             признак клиента (бизнес-жюри 23.09, раунд 5). Клиента выдают
#             продукт и операция — «кредит», «заявка», «карта» — и они
#             остаются основами; «банкомат» и «банковский» тоже;
#   idiom   — основа, у которой есть устойчивый небанковский оборот
#             «X в <что-то>»: «вклад в науку», «вклад Пушкина в литературу».
#             Слово не засчитывается, если в пределах трёх слов за ним стоит
#             «в»/«во», а за предлогом — слово со строчной буквы, само не
#             банковское. «Вклад в банке», «вклад в рублях», «вклад в
#             Сбербанке» засчитываются.
#
# Принцип отбора — обратный counter_public: там только редкие фамилии, чтобы
# вето не отнимало защиту у клиента; здесь слова, которые в предложении со
# знаменитостью почти всегда означают клиента. Ошибка в сторону лишней маски
# стоит штрафа, ошибка в сторону вето — утечки. Поэтому сюда НЕ входят слова,
# которые встречаются в ловушках корпуса и в рассказах о знаменитостях:
# «финансовой грамотности», «программа», «открыл» (Менделеев открыл закон),
# «поступление» (в лицей), «зачислили» (в полк), «операция», «ставка», «акция».
#
# Основы — не короче четырёх букв, если запись не exact: короткая основа
# ловит случайные слова. Ключи нормализуются при загрузке: регистр и «ё»
# значения не имеют.
