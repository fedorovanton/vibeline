# Контекст имени латиницей для сканера latin (scan_latin.go): слово или
# фраза и метка — роль записи. Ключи нормализуются при загрузке.
#
# Метки:
#   marker   — маркер лица слева от имени: «Client Ivan Petrov», «перевод от
#              Dmitry Tsoy». Имя за ним маскируется без реквизитов рядом.
#   title    — обращение: «Mr. Oleg Melnik». Как marker, и точка после него
#              предложение не завершает.
#   work     — произведение: «роман Anna Karenina», «novel …». Имя рядом —
#              название, а не человек (контр-правило).
#   stop     — слово с заглавной, которое не бывает частью имени: разрывает
#              ряд слов, само в спан не входит.
#   place    — объект, названный по имени: «Victoria Station», «Ivan Petrov
#              Street». Ряд, стоящий вплотную к такому слову, — название
#              места или организации, а не человек (контр-правило).
#   particle — строчная частица внутри имени: «Anna van der Berg».
#   phrase   — бренд, место или персонаж, где первое слово — личное имя:
#              «Hugo Boss», «Calvin Klein». Ряд, начатый фразой, — не ПД,
#              даже за маркером лица («made by Hugo Boss»). Поэтому сюда не
#              вносятся бренды, совпадающие с обычным ФИО («Paul Smith»).
#
# Маркеры держателя карты («держатель», «card», «name», «имя») здесь не
# ведутся: имя за ними — зона сканера держателя (scan_misc.go).
