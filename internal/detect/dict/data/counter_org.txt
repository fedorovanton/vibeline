# Маркеры, слева от которых находка не является персональными данными
# физического лица. Метка различает назначение записи:
#
#   toponym — название объекта, в которое входит фамилия: «улица Пушкина»,
#             «музей Пушкина», «имени Королёва». Снимается только ФИО;
#             адрес остаётся адресом, вето на pii.Address не ставится.
#   org     — организация и её контакты: «отделение банка по адресу …»,
#             «горячая линия …». Снимаются адрес, телефон и email в окне
#             справа: контакты организации персональными данными не являются.
#             Слева маркер работает в обороте «X — адрес нашего офиса»;
#   owner   — владелец контакта только в обороте «X — адрес партнёра»:
#             справа от себя окна не открывает, потому что «партнёр Иван
#             Петров, тел. …» — это человек;
#   memorial — «памяти X», «в честь X»: снимается ФИО X в родительном
#             падеже, как у toponym, и больше ничьё в предложении
#             (T-67, раунд 4 жюри);
#   tribute — «к юбилею X», «по местам X», «с портретом X»: то же, но только
#             если в имени X есть фамилия из counter_public. Юбилей бывает и
#             у клиента, а юбилей Гагарина — только у Гагарина;
#   mention — упоминание публичного лица (T-82, бизнес-жюри 23.09, раунд
#             5): «цитата от Льва Толстого», «собрание сочинений Льва
#             Толстого», «в творчестве Анны Ахматовой», «выставка Ивана
#             Айвазовского», «к дню рождения Фёдора Достоевского». Как
#             tribute: вето только на имя за словом и только если в нём есть
#             фамилия из counter_public. Между словом и именем допускается
#             предлог «от», «о», «про» и одно строчное слово перед ним:
#             «цитата дня от …». В отличие от tribute, без имени за словом
#             правило 4 не ослабляет: «Юрий Гагарин дал интервью и оформил
#             кредит» — клиент;
#   work    — произведение: «роман «Анна Каренина»», «по роману Льва
#             Толстого», «фильм о Владимире Высоцком». Снимаются название в
#             кавычках и имя автора или героя за словом — последнее только
#             если в нём есть фамилия из counter_public: «Картина Ивана
#             Петрова продана, деньги на счёт …» — ФИО продавца, а не
#             художника (T-82). Слово-имя с заглавной буквы работает только
#             перед кавычкой: «Роман Иванов» — имя; «Картина Ильи Репина» —
#             произведение.
#
# Записи односложные: в справочник вносится самое характерное слово оборота,
# а не оборот целиком. «Юридический адрес», «горячая линия», «служба
# поддержки», «пункт выдачи» опознаются по словам «юридический», «горячая»,
# «поддержки», «пункт» — слова «адрес», «линия» и «служба» сами по себе
# маркером не являются, иначе «проживает по адресу …» перестало бы
# маскироваться. По той же причине здесь нет слова «фактический»:
# фактический адрес — это адрес человека.
#
# Ключи нормализуются при загрузке: регистр и «ё» в файле не важны.
# Однобуквенные и двухбуквенные сокращения («ул», «пр», «им») сканер
# принимает и без точки: точку лексер выделяет отдельным токеном.
