# Числительные, из которых складывается число, записанное словами: день месяца
# («шестнадцатое февраля») и год («тысяча девятьсот девяностого»).
#
# Формат метки: роль и значение разряда.
#   c — количественное. Само по себе число не завершает: «тысяча» может быть
#       началом года, а может быть суммой в рублях.
#   o — порядковое. Завершает число. Из-за этого «тысяча рублей» и «двадцать
#       человек» кандидатами не становятся вовсе: порядкового в них нет.
#
# Составные формы в справочник не вносятся: «двадцать первого» и «тысяча
# девятьсот восемьдесят пятого» складываются сканером по разрядам. Иначе одни
# только дни в двух падежах дали бы шесть десятков строк, а годы — тысячи.
#
# Регистр и «ё» не дублируются: и лексер, и загрузчик справочника приводят
# запись к одной форме.
