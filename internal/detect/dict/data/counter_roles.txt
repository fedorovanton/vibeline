# Ролевые слова публичных персон. Присутствие такого слова слева от имени
# означает, что речь идёт об известном человеке, а не о клиенте: «поэт
# Александр Пушкин» — не персональные данные.
#
# Падежные формы перечислены явно: сканер сравнивает нормализованный токен
# целиком и морфологию не разбирает. Ключи нормализуются при загрузке,
# регистр и «ё» в файле не важны.
#
# Метка записи (T-67, раунд 4 жюри):
#   пусто  — роль исторической или публичной фигуры: имя сразу за ролью
#            (через другие роли и союз «и») снимается без условий;
#   office — государственная должность, публичная сама по себе: «министр»,
#            «губернатор», «мэр». Между должностью и именем допускается
#            дополнение: «министр финансов Антон Силуанов», «губернатор
#            Московской области …». Правило молчит, если в предложении есть
#            маркер клиента, реквизит, его название или банковская операция
#            с лицом («перевод от …»);
#   chair  — должность, которая публична только при государственном органе:
#            «председатель ЦБ», «глава Минфина», «депутат Госдумы».
#            «Председатель ТСЖ Иванова», «глава отдела Петров» — сотрудники
#            и соседи, их имена защищаются; без слова body в дополнении
#            правило молчит. В остальном — как office;
#   fame   — профессия, публичная только в новостном тексте (T-82,
#            бизнес-жюри 23.09, раунд 5): «вратарь Игорь Акинфеев»,
#            «основатель Telegram Павел Дуров», «пресс-секретарь Дмитрий
#            Песков». Такая профессия бывает и у клиента, поэтому правило
#            строже должности: молчит при маркере клиента, реквизите, его
#            названии, банковской операции с лицом и при банковском слове
#            в предложении, а имя обязано стоять сразу за словом —
#            «основатель компании Иванов Иван» остаётся под маской.
#            Составная роль через дефис записывается целиком:
#            «пресс-секретарь»;
#   body   — государственный орган или территория в дополнении должности:
#            «ЦБ», «Минфина», «правительства», «области». Ролью само по
#            себе не является.
#
# Чего здесь нет намеренно:
#   * «клиент», «заявитель», «сотрудник», «гражданин», «плательщик» — это,
#     наоборот, маркеры персональных данных, они живут в name_markers.txt;
#   * должности и профессии живых людей рядом с нами — «врач», «профессор»,
#     «директор», «менеджер», «инженер», «водитель». Врач Иванова — это
#     сотрудник, её имя защищается, а не снимается с маскирования.
# Список остаётся списком ролей исторических и публичных фигур.
