# Справочник личных имён латиницей: имя, метка рода.
# Метка: m — мужское, f — женское, mf — встречается в обоих списках.
# Ключи нормализуются при загрузке: «IVAN», «Ivan» и «ivan» — одна запись.
#
# Два блока в одном списке: транслитерации русских, украинских, кавказских и
# среднеазиатских имён в основных схемах (загранпаспорт, ГОСТ, устаревшие
# «Sergey», «Yulia») и распространённые европейские и английские имена.
#
# Сканер latin (scan_latin.go) принимает имя только в паре с соседним словом
# с заглавной буквы, поэтому одно имя ПД не делает. Намеренно НЕ включены
# имена, совпадающие с частыми английскими словами, месяцами, топонимами и
# брендами: May, June, April, August, Will, Grace, Hope, Faith, Joy, Art, Guy,
# Sue, Rich, Chase, Page, Summer, Dawn, Jay, Rose, Lily, Iris, Ruby, Amber,
# Jade, Madison, Austin, Jordan, Florence, Georgia, Virginia, Carolina,
# Sydney, Mercedes, Lada, Max, Jan, Per, Pat, Dean, Rosa, Alan, Rada.
# «Kim» — частая фамилия («SERGEY KIM»), поэтому как имя не ведётся.
