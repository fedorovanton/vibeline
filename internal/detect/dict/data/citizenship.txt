# Гражданство: названия стран и производные от них прилагательные и
# существительные. Метка записи — код страны по ISO 3166-1 alpha-2.

# Справочник отвечает только за форму значения. Решение, что перед нами
# гражданство человека, а не упоминание страны, принимает сканер по маркеру
# слева («гражданство», «гражданин», «подданство»): без маркера кандидат
# остаётся слабым, и его судьбу решает движок.
#
# Ключи нормализуются при загрузке, поэтому регистр и «ё» здесь не важны.
# Многословные записи сравниваются целиком: «Российская Федерация» — одна
# запись, а не две.
#
# Намеренно не включены односложные названия, совпадающие с обиходными
# русскими словами («Того», «Чад», «Мали»): цена ложного срабатывания на
# служебном слове выше пользы от редкой страны.
