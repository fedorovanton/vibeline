# Фамилии широко известных исторических и публичных лиц вместе с падежными
# формами основы. Ключи нормализуются при загрузке, поэтому регистр и «ё»
# в файле значения не имеют.
#
# Метка записи. Пустая — обычная запись. official (T-67) — финансовый
# чиновник или глава крупнейшего банка, о котором банк пишет в новостях:
# «Эльвира Набиуллина сообщила о ключевой ставке — вклады подорожают».
# Рядом с ним банковские слова («ставка», «вклады») и названия карты и
# счёта — тема новости, а не признак клиента, поэтому вето снимают только
# маркер клиента, цифровой реквизит, почта, название паспорта или телефона
# и банковская операция с лицом («перевод от …»).
#
# Справочник читает ТОЛЬКО правило 4 контр-правил, и оно намеренно самое
# осторожное из четырёх: вето снимается, если в предложении есть маркер
# клиента или цифровые реквизиты. Однофамилец-клиент по фамилии Пушкин
# обязан защищаться — пропуск ПД дороже лишней маски.
#
# Отсюда принцип отбора: сюда попадают только РЕДКИЕ среди обычных людей
# фамилии. Распространённые (Попов, Павлов, Смирнов, Кузнецов, Волков,
# Морозов, Жуков, Титов, Миронов, Калашников) не включены намеренно, хотя их
# носили известные люди: контекст «поэт X», «улица X», «музей X» ловится
# правилами 1 и 2 без всякого списка, а список бы отнял защиту у клиента
# с такой фамилией.
#
# Составные фамилии через дефис (Римский-Корсаков, Салтыков-Щедрин,
# Миклухо-Маклай) не включены: лексер разбивает их на отдельные токены,
