# метка — машинный ключ типа ПД.
#
# Маркер сам по себе кандидата не создаёт: он лишь говорит, какому документу
# принадлежит найденное рядом число. Форма проверяется отдельно, а для СНИЛС,
# ОГРН и VIN есть ещё и контрольная сумма.
#
# Словоформы перечисляются, а не выводятся отсечением окончаний: список
# короткий, а добавление формы не требует правки кода.
#
# Слово «номер» сюда намеренно не входит: оно стоит при любом реквизите и
# маркером ничего не различает.
