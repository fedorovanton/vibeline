# Стоп-слова сканера ФИО (T-66, раунд 4 жюри): слова, которые стоят с
# заглавной буквы вплотную к имени или на месте одиночной фамилии, но
# фамилией не бывают.
#
# Сканер принимает фамилию без суффикса («Коваль Инна», «Ваш клиент, Кох.»,
# «Фамилия: Волк») по позиции, а не по списку фамилий. У такого правила нет
# положительных признаков, одни отсевы, и этот справочник — один из них:
# обращения, титулы, организации, вопросительные слова, родство, профессии,
# банковские и бытовые существительные, которые начинают предложение перед
# именем («Менеджер Ольга», «Заявка Олега», «Где Анна?») или стоят на месте
# значения поля («Фамилия: указана неверно»).
#
# Служебные слова, местоимения, предлоги, приветствия и часть должностей
# перечислены в коде (nameBareStopWord); ролевые слова контр-правил
# («поэт», «художник») читаются из counter_roles; города, месяцы и
# государства — из своих справочников. Сюда их повторять не нужно.
#
# Формат: одно слово в строке, в той форме, в какой оно стоит в тексте;
# регистр и «ё» приводятся при загрузке. Метка не используется.
