## Что сделать

1. **Распознать голый payload.** Весь текст (после обрезки пробелов и
   концевой пунктуации) — одно значение: коротко (порядок 1–8 слов, до
   ~200 байт), нет структуры предложения (нет глаголов/служебных связок
   «просит», «клиент», «и», нет второго предложения). Проверка дешёвая и
   срабатывает только на коротком входе — на длинных текстах ноль затрат.
2. **Слабый кандидат на весь payload → Strong.** Если единственный кандидат
   (или цепочка кандидатов одного типа) накрывает весь payload с точностью до
   пробелов и пунктуации — поднять до Strong, как это делает подъём по
   кластеру (`promoteByCluster`), с пометкой правила (`+bare`).
3. **Кандидата нет — классификатор формы целиком строки.** Детерминированно,
   по форме и справочникам детектора (читать можно любые, менять — только свои
   файлы):
   - `ddd` → cvv; `dddd` → pin; `ddd-ddd` → passport_dept_code;
   - `dddd dddddd` / 10 цифр подряд → passport_number; `dd dd dddddd` →
     driver_license; 10 цифр, начинающиеся с `9`, → phone;
   - дата любой поддерживаемой формы → birth_date (голая дата выдачи
     неотличима; тип хуже пропуска не бывает — пропуск штрафуется сильнее);
   - «Российская Федерация», «РФ», «Россия», «гражданин РФ», прочие значения
     справочника гражданства → citizenship;
   - начинается с органа (ГУ/ОВД/УФМС/ОУФМС/МВД/«Отделом»/«Отделением»/ТП …)
     → passport_authority;
   - населённый пункт (`г. X`, справочник городов, «X области») без улицы и
     дома → birth_place;
   - 1–3 слова кириллицей с заглавной, из которых хотя бы одно — имя, отчество
     из справочника или фамилия по суффиксу/справочнику → full_name;
   - 2–3 слова латиницей (UPPER или Title), похожие на имя и фамилию →
     card_holder.
   Всё, что не подошло, остаётся без изменений: `mask(T)==T` для обычного
   текста без ПД не нарушается.
4. Только под профилем `balanced` и `paranoid` (как подъём по кластеру —
   проверить в коде, как профили устроены); `strict` — без изменений.
5. **Корпус.** В `tools/corpusgen` — вид записей `bare` (голые значения всех
   17 типов в разных формах) **за флагом** `-bare` (по умолчанию выключен,
   чтобы не менять корпус seed 20260922 и сравнимость прошлых прогонов).
   Генератор не должен использовать грамматики и справочники детектора
   (`independence_test.go`).
