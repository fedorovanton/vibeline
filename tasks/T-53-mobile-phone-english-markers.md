## Почему задача появилась

Бизнес-жюри 23.09 (`.agents/runtime/jury-exec-review/20260923/REPORT.md`):

```
Мой номер 89161234567, перезвоните после 18  →  без изменений
Ivan Ivanov, passport 4509 123456             →  без изменений
```

Телефон без слова «телефон» получал `Weak` и в одиночном предложении не
маскировался; английское «passport» маркером не считалось.

## Что сделано

- Мобильная форма (`7`/`8` + `9xx` + 7 цифр) — `Strong` без маркера, кроме
  соседства с маркером договора. Городские номера без маркера — `Weak`, как
  было. Решение I-20.
- Маркеры `passport`, `driver`, `licen…`, `phone`, `mobile`, `tel`.

## Критерии приёмки

- [x] AC-1 Обе фразы выше маскируют номер на живом `/process`
      («Мой номер [ТЕЛЕФОН_1]», «passport [ПАСПОРТ_1]»).
- [x] AC-2 «Горячая линия банка 8 800 100-00-00», «Номер договора
      89161234567 закрыт» — без маски.
- [x] AC-3 Прогон качества не хуже.
