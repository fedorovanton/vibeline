## Что сделать

1. **С-4.** После отбора спанов закрывать тем же плейсхолдером все точные
   вхождения уже найденного значения, стоящие по границам токенов (не внутри
   другого числа или слова). Тогда `VerifyReplaced` на таком тексте проходит,
   а открытых повторов на `/process` не остаётся. Поведение на обычных
   входах `/process` сохранить (эталон `benchmarkGolden`, прогон качества —
   итоги не хуже).
2. **С-5.** `VerifyReplaced` — за один проход по тексту (множество
   значений; поиск по началу-токену или Aho-Corasick без регулярных
   выражений). Замер до/после на 600 КБ / 15 000 спанов.
3. **С-6.** Резерв буквальных плейсхолдеров — и на `/api/v1/mask`;
   восстановление — одна реализация для прокси и явного API.
4. **Ж-1.** При восстановлении ответа модели распознавать выданный
   плейсхолдер и без квадратных скобок в обрамлении разметки (`**ФИО_1**`,
   `*ФИО_1*`, `` `ФИО_1` ``) — только выданные в этой области метки, чужое не
   раскрывается.
5. **Ж-2.** На стенде политику выбирает ключ: потребитель без права
   `demask` не может получить восстановленный ответ, выбрав чужую политику.
